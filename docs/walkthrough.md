# 现场复核

先在画外完成依赖或镜像准备。服务就绪检查为 `/health`，启动不下载资料。打开首页，选择日期类型，查看日记中的并行照护与观察缺口；从任一明细点开原始记录核对。保存一次当前材料，然后改动选择并重新计算，再打开刚才的记录，确认原范围仍在，最后导出。

上述操作的设计时长为45至75秒，留出异常提示时间后不超过90秒。部署故障不隐藏也不回放旧结果。新增分析的实际结果和可操作性须在功能完成后重新验证；这里不预报尚未开发能力的演示结果，不限定显著性或结论方向。

## 研究估计与口径复核

研究估计随范围自动运行，显示在"研究估计"区：周户均钟表时间与折算负担（含95%置信区间）、周负担分布分位数、群体差异、折算敏感性网格、提供者任务分担、接收端照护量与日记级强度明细。在侧栏"研究口径"修改主活动/伴随/待命折算系数、半天日记与代填处理、分组方式和敏感性网格，点"运行研究估计"重算；结论对折算的敏感程度直接反映在网格与备注中。"恢复默认口径"回到 `product.json` 的配置。

保存当前描述会把口径与研究估计一并冻结；之后再改口径保存新记录，打开旧记录仍显示原来的分摊结果。不含研究估计的旧记录照常打开，可按当前口径补算。

## 家庭时间轴

"家庭时间轴"区按当前范围列出家庭，选择后绘制工作日与周末两行组：每名提供者一行（代填有标记，灰色为未观测时段，不视为休息），接收端每个被照护者一行（颜色深浅表示同时照护的提供者数），红色虚线为次日0:00。点击任一活动条查看原始记录，用于核对并行照护、跨午夜延续与覆盖缺口。

含研究估计与时间轴的完整复核约需90至120秒。
