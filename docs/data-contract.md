# 资料与统计口径

`diaries` 一行是某提供者某天的日记，家庭是抽样单位，提供者可同属一户；`stratum/psu/weight` 描述设计。`observed_start/observed_stop` 表示填报覆盖，`proxy` 为代填，不把覆盖外解释成空闲。`activities` 按 `[start,stop)` 记录分钟，跨午夜 stop 可超过1440，归属于开始日日记但分析须明确跨天处理且不能重复计入。同一人同时多项活动、不同人同照一个接收者都是合法事实。`primary/secondary/standby` 是角色而不是预先固定的数值权重。`design` 的5个工作日及2个周末日是目标周构成，不按回收份数决定。描述性浏览仍显示填报分钟总和；研究估计按下述口径另行计算。

## 原始表

- `diaries`：256条示例，主键为 `diary`。字段：`diary`, `household`, `provider`, `day_type`, `area`, `day_start`, `observed_start`, `observed_stop`, `proxy`, `weight`, `stratum`, `psu`。
- `activities`：示例活动记录，主键为 `activity`。字段：`activity`, `diary`, `start`, `stop`, `kind`, `recipient`, `task`。
- `design`：64条示例，主键为 `household`。字段：`household`, `workday_factor`, `weekend_factor`, `sampling_unit`。

## 研究口径（caliber）

研究估计的全部可改假设集中在口径对象里，随分析记录一起冻结：

- `factors`：`primary/secondary/standby` 三个角色的折算系数（0至2），主活动为参照尺度。
- `partial`：半天日记（覆盖不足1440分钟）处理。`exclude` 排除出周估计；`scale` 保留并按 1440/覆盖分钟 放大（假设未观测时段与已观测相同，属口径选择而非事实）。
- `proxy`：`include` 保留代填日记；`exclude` 排除，用于敏感性对照。
- `group_by`：`area` 按家庭区域比较；`none` 不分组。
- `sensitivity`：`secondary/standby` 各自的网格取值（每维1至8个），用于重算结论。

未知字段、越界系数、非法枚举一律拒绝，不静默改换口径。默认口径在 `product.json`。

## 测量定义

一切日内测量只落在覆盖窗口 `[observed_start, observed_stop)` 内；未观测时段是未观测，不视为休息，也不计为零。

- 钟表时间：窗口内活动区间的并集，不超过覆盖长度。
- 填报分钟：各活动区间直接相加，可因并行超过窗口长度，即家属反映的"超过二十四小时"。
- 折算负担：Σ 折算系数×角色分钟（含跨午夜延续），并行活动分别折算，可超过钟表时间，反映强度。
- 并行分钟/最大并行：窗口内两项及以上活动同时进行的时间与峰值。
- 多接收者分钟：一人同时照看老人和孩子等两个及以上接收者的时间。
- 跨午夜延续：stop 超过日记日终点的部分，归属于起始日记，只计入折算负担与填报分钟，不进入当日钟表时间，也不计入其他日记，因此不重复。
- 窗口前记录：start 早于覆盖起点的部分，仅作资料质量提示，不进入任何测量。

接收端与提供端分开：接收钟表时间为同一接收者跨提供者区间的并集；接收人时为各提供者分别累计；双重照护分钟为两名及以上提供者同时照护同一接收者的时间。

## 周负担与总体估计

周负担 = workday_factor × 工作日日均 + weekend_factor × 周末日均，因子来自 `design` 表（目标周构成），工作日与周末不按回收份数混算。户周负担为户内各提供者之和（提供端人时，可超过每周10080分钟）。总体均值与组间差按户权重加权，方差为分层 PSU 线性化（with-replacement 近似），自由度 = PSU 数 − 层数，给出95%置信区间；单 PSU 层的方差贡献按0处理并在备注中说明。分位数为加权点估计，未附区间。敏感性网格在伴随/待命系数组合上重算周户均折算负担与组间差，报告均值范围与组间差符号是否翻转；钟表时间结果不随折算系数变化。

## 版本与扩展

`fixtures/data.json` 是完整导入材料，由 `fixtures/generate.py` 以固定种子独立生成，不含真实家庭信息；`product.json` 是当前浏览器默认选择与默认口径。全量导入校验后按规范化内容指纹保存，相同内容不重复建版本。原始事实不原地修改；资料修订形成新版本。`null` 表示明确未观测，不因筛选或合计自动变为0。

`care_time/domain.py` 是领域入口（校验、描述、研究估计编排）；`care_time/measures.py` 是日记级与家庭日级测量；`care_time/estimate.py` 是周负担与抽样设计估计；`service.py` 连接范围选择、数据版本与服务端计算后的存档；`storage.py` 管理不可变数据和保存材料；`web/app.js` 提供浏览、口径修订、时间轴和导出交互。保存的材料同时包含原数据、选择、口径与结果，打开旧材料不重算为新数据；同一数据版本同一口径重算必然得到同一结果。统计方法、模型选择和业务结论没有预设答案。
